- [x] **[2026-07-03] Little Farm Builder.** Gesture-only farming simulation, the eleventh game and a deliberate complexity step-up (requested explicitly: "something more complex" than the session-based match/sort games). First game with a **persistent, evolving save state** — a farm that keeps growing in real time between visits, not a per-session best score — and the first to use **continuous pinch-and-drag** instead of hover-and-dwell as its core interaction. Pinch-grab a seed from the tray, drag it onto an empty plot, release to plant (costs coins); crops grow through seed → sprout → ripe stages based on real elapsed wall-clock time (derived from a persisted `plantedAt` timestamp vs. `Date.now()`, so growth continues even while the game is closed). Pinch-grab a ripe crop and drag it to the basket to harvest for coins. Four crops (Carrot 20s/cheap/starter, Tomato 60s, Corn 3min, Pumpkin 8min/priciest) and a 4-to-12 expandable plot grid, both unlocked with coins via ordinary hover-dwell buttons — only planting/harvesting use the new pinch-drag mechanic. New `isPinching` hand-frame primitive (thumb-index tip distance, threshold reused from `gesture-love-balls`) with a 100ms sustain-before-grab debounce to absorb landmark jitter (same fix `gesture-love-balls` already needed). New `usePinchDrag` hook extends `HoverButton`'s proven DOM-rect hit-testing idiom to a grab/carry/drop flow instead of building a canvas drag engine. No fail state: coins only go up, plots only unlock. 6 achievements (First Harvest, Green Thumb, Full Table, Land Baron, Century Farmer, Master Grower). Score submitted to the platform is lifetime total coins earned (monotonic, so it behaves like a normal high score even though there are no discrete rounds) — no DB schema changes needed, same generic `public.scores` table as every other game. `tsc --noEmit` + `vite build` clean on the first pass; served from `public/games/farm-builder/`. Highest-risk untested piece: the pinch-drag mechanic itself has never been exercised against a live hand in this build environment — a webcam pass is strongly recommended before shipping. (ADR-045)
